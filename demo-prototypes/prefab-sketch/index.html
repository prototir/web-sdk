prefab-sketch

prefab-sketch@0.1.0
Available · 1 KB

What it gives you

A tiny, production-ready 2D canvas loop with animation timing, high-DPI scaling, responsive resizing, and unified pointer/touch coordinates.

Why use it

  • Start generative art or visual experiments without canvas boilerplate.
  • Draw in CSS pixels while the module handles sharp high-DPI output.
  • Receive consistent time, delta, frame, size, and pointer state every frame.

The essential code

import { createSketch } from 'prefab-sketch';

createSketch({
  draw(ctx, { t, dt, width, height, mouse }) {
    // Render one responsive frame.
  }
});
