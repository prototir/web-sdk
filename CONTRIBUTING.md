# Contributing

Issues and focused pull requests are welcome. Before opening a pull request:

1. Discuss behavior or protocol changes in an issue first.
2. Run `npm ci` followed by `npm run check`.
3. Add tests for public behavior and update the README when the API changes.
4. Keep payloads small, free of personal data, and compatible with the sandboxed iframe model.
